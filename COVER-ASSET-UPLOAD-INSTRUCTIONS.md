# DPC Clean Cover Upload Instructions

Use `DPC_book_cover_assets_v1.2.zip` as the controlling package.

For each title, upload the package file named `cover-front.webp` into the matching repository directory:

`assets/img/books/<slug>/cover-front.webp`

Do not rename the file. Do not delete `cover-front.svg`; it is the resilient wrapper used by the website and will automatically display the WebP once present.
