# DivinityxPublishing.com

Official static website for Divinityx Publishing Company.

## Build Room 01

- Static HTML, CSS, and JavaScript
- GitHub Pages compatible
- Dynamic base path for project preview and custom domain
- Seventeen-title publication catalog
- Four confirmed author routes
- Accessible mobile navigation and catalog filters
- Safe retailer links

## Local preview

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

## GitHub Pages

Deploy from `main` and repository root after the Build Room 01 branch is reviewed and merged. Add a `CNAME` only after DNS is ready.
